### 💬 ReviewIQ — Customer Review Sentiment Analysis

A sentiment analysis system that classifies product reviews as Positive, Negative, or Neutral using text data mining, comparing Logistic Regression and Multinomial Naive Bayes.

<a href="https://github.com/ShashwatBujone/ReviewIQ-Customer-Sentiment-Analysis">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=ShashwatBujone&repo=ReviewIQ-Customer-Sentiment-Analysis&theme=nord&border_color=7dd3fc&title_color=7dd3fc&icon_color=7dd3fc" alt="ReviewIQ repo card"/>
</a>

| Layer | Technology |
|-------|------------|
| Language | Python |
| Data Handling | Pandas, NumPy |
| Feature Extraction | Text preprocessing + TF-IDF |
| Models | Logistic Regression, Multinomial Naive Bayes (Scikit-learn) |
| Evaluation | Confusion matrix, accuracy, precision, recall, F1-score |

[![Code](https://img.shields.io/badge/Code-GitHub-7dd3fc?style=for-the-badge&logo=github&logoColor=7dd3fc&labelColor=0f172a)](https://github.com/ShashwatBujone/ReviewIQ-Customer-Sentiment-Analysis)
